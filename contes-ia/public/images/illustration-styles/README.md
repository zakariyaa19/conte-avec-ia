# Images des Styles d'Illustration

Ce dossier contient les images de fond pour les cartes de sélection du style d'illustration.

## Fichiers requis (à ajouter)

Les images suivantes doivent être placées dans ce dossier :

1. **aquarelle.jpg** - Style aquarelle doux et fluide
2. **animation-3d.jpg** - Style animation 3D type Pixar
3. **monde-des-blocs.jpg** - Style Minecraft/blocs
4. **papier-decoupe.jpg** - Style papier découpé artisanal
5. **clay-animation.jpg** - Style pâte à modeler/claymation
6. **kawaii.jpg** - Style kawaii japonais mignon
7. **geometrique.jpg** - Style géométrique moderne
8. **livre-illustre.jpg** - Style livre illustré classique
9. **dessin-japonais-manga.jpg** - Style manga/anime japonais

## Spécifications techniques

- Format : JPG (optimisé pour le web)
- Dimensions recommandées : 800x600px minimum
- Poids : < 200KB par image
- Qualité : 80-85%
- Ratio : 4:3 ou 16:9

## Utilisation

Ces images sont utilisées comme arrière-plan des cartes de sélection dans la section "🎨 Style d'illustration" du formulaire.

Chemin d'accès : `/images/illustration-styles/{nom-fichier}.jpg`
