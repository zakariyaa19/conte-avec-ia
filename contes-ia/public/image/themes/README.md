# Images des Thèmes Généraux

Ce dossier contient les images PNG pour les cartes de sélection du thème général du conte.

## Fichiers requis (à ajouter)

Les images suivantes doivent être placées dans ce dossier :

1. **educatif.png** - Éducatif (petit garçon avec livre + crayon)
2. **contes-de-fees.png** - Contes de fées (enfant + château/fée)
3. **activites.png** - Activités (enfant qui peint/joue)
4. **histoires.png** - Histoires (enfant lisant un livre)
5. **fetes.png** - Fêtes (enfant avec ballon/guirlande)
6. **famille.png** - Famille (enfant avec parents/famille)

## Spécifications techniques

- Format : PNG (avec transparence)
- Dimensions recommandées : 400x400px (carré)
- Poids : < 100KB par image
- Style : Illustration jeunesse colorée et sympathique
- Fond : Transparent ou uni clair

## Style visuel

- Personnages enfants souriants et accueillants
- Style illustration moderne et coloré
- Représentation claire du thème
- Couleurs vives et attrayantes
- Cohérence visuelle entre toutes les images

## Utilisation

Ces images sont utilisées dans les cartes de sélection du thème général du conte.

Chemin d'accès : `/image/themes/{nom-fichier}.png`
