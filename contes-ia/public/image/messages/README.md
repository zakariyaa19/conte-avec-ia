# Images des Messages Centraux

Ce dossier contient les images PNG pour les cartes de sélection des messages centraux à transmettre.

## Fichiers requis (à ajouter)

Les images suivantes doivent être placées dans ce dossier :

1. **amitie.png** - Amitié (enfants se tenant la main ou jouant ensemble)
2. **courage.png** - Courage (enfant brave face à un défi)
3. **nature.png** - Prendre soin de la nature (enfant plantant un arbre ou arrosant des fleurs)
4. **amour.png** - Amour (enfant avec cœur ou câlin familial)
5. **perseverance.png** - Persévérance (enfant déterminé atteignant un objectif)
6. **partage.png** - Partage (enfants partageant jouets ou nourriture)
7. **honnetete.png** - Honnêteté (enfant sincère ou transparent)
8. **respect.png** - Respect (enfants s'entraidant ou se respectant)
9. **personnalise.png** - Message personnalisé (enfant avec étoile ou livre)

## Spécifications techniques

- Format : PNG (avec transparence)
- Dimensions recommandées : 400x400px (carré)
- Poids : < 100KB par image
- Style : Illustration jeunesse colorée et sympathique
- Fond : Transparent ou uni clair

## Style visuel

- Personnages enfants expressifs et positifs
- Style illustration moderne et coloré
- Représentation claire de la valeur/message
- Couleurs vives et adaptées à chaque message
- Cohérence visuelle entre toutes les images

## Utilisation

Ces images sont utilisées dans les cartes de sélection du message central du conte.

Chemin d'accès : `/image/messages/{nom-fichier}.png`
