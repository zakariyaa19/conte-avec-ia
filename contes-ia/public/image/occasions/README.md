# Images des Occasions

Ce dossier contient les images PNG pour les cartes de sélection des occasions spéciales.

## Fichiers requis (à ajouter)

Les images suivantes doivent être placées dans ce dossier :

1. **anniversaire.png** - Anniversaire (enfant avec gâteau et bougies)
2. **noel.png** - Noël (enfant avec sapin et cadeaux)
3. **nouvel-an.png** - Nouvel An (enfant avec feux d'artifice)
4. **paques.png** - Pâques (enfant avec œufs et lapin)
5. **aid.png** - Aïd el-Fitr (enfant en tenue festive avec croissant de lune)
6. **fete-meres.png** - Fête des mères (enfant offrant des fleurs)
7. **fete-peres.png** - Fête des pères (enfant avec cadeau pour papa)
8. **halloween.png** - Halloween (enfant déguisé avec citrouille)
9. **personnalise.png** - Occasion personnalisée (enfant avec calendrier/étoile)

## Spécifications techniques

- Format : PNG (avec transparence)
- Dimensions recommandées : 400x400px (carré)
- Poids : < 100KB par image
- Style : Illustration jeunesse colorée et sympathique
- Fond : Transparent ou uni clair

## Style visuel

- Personnages enfants souriants et festifs
- Style illustration moderne et coloré
- Représentation claire de l'occasion
- Couleurs vives et adaptées à chaque fête
- Cohérence visuelle entre toutes les images

## Utilisation

Ces images sont utilisées dans les cartes de sélection de l'occasion du conte.

Chemin d'accès : `/image/occasions/{nom-fichier}.png`
