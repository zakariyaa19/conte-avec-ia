# Images des Tranches d'Âge

Ce dossier contient les images PNG pour les cartes de sélection d'âge.

## Fichiers requis (à ajouter)

Les images suivantes doivent être placées dans ce dossier :

1. **age-0-2.png** - Bébé/tout-petit (0-2 ans)
2. **age-3-5.png** - Enfant préscolaire (3-5 ans)
3. **age-6-9.png** - Enfant d'âge scolaire (6-9 ans)
4. **age-10-plus.png** - Préadolescent/adolescent (10+ ans)

## Spécifications techniques

- Format : PNG (avec transparence)
- Dimensions recommandées : 400x400px (carré)
- Poids : < 100KB par image
- Style : Illustration jeunesse colorée et sympathique
- Fond : Transparent ou uni clair

## Style visuel

- Personnages enfants souriants et accueillants
- Style illustration moderne et coloré
- Représentation claire de l'âge (taille, traits, activités)
- Couleurs vives et attrayantes

## Utilisation

Ces images sont utilisées dans les cartes de sélection d'âge de l'enfant (première étape du formulaire).

Chemin d'accès : `/image/ageenfant/{nom-fichier}.png`
